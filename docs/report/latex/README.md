# Building the report

```
cd docs/report/latex
python build.py            # regenerate from the Markdown, then build
python build.py --pdf-only # build from the committed .tex, no pandoc needed
```

Or, if you would rather drive LaTeX yourself:

```
pdflatex main
bibtex main
pdflatex main
pdflatex main
```

**Do not chain those with `&&`.** `bibtex` exits with status 2 whenever it
emits a warning, and this bibliography has real warnings — three entries are
still missing fields. A chained script stops there, never regenerates the
`.bbl`, and the next two passes silently use a stale bibliography. That
mistake produced a wrong References page during this file's own development.

## What is generated and what is source

| path | role |
|---|---|
| `../chapter*.md`, `../SRS.md` | **the source.** Edit these. |
| `chapters/*.tex` | generated by `build.py`; committed so the PDF builds with only a TeX distribution |
| `references.bib` | generated from `../references.bib` |
| `main.tex` | **hand-written.** Preamble, title page, structure. |
| `figures/*.png` | copied from `docs/diagrams/` |

Editing `chapters/*.tex` works until the next `build.py`, which overwrites
them. Either edit the Markdown, or adopt the `.tex` as source and stop running
`build.py` — but not both.

## Draft notes

Each chapter carries boxed notes addressed to the author: what needs checking,
what is blocked, what must not be submitted as it stands. They are not part of
the report.

In `main.tex`:

```latex
\draftnotestrue    % notes visible - the state while anything is blocked
\draftnotesfalse   % notes vanish - the submission build
```

Leave it `true` until every note is resolved, so that one cannot be submitted
by accident. There are 13 at present.

## Three transformations the bibliography needs

`build.py` applies these because BibTeX requires them and the source file
should stay readable:

1. **`%` comments inside an entry are stripped.** BibTeX rejects them with
   "You're missing a field name", and the field that follows is lost. This
   silently cost `frantzeskou2006` and `abuhamad2019` their author lists.
2. **`@software` becomes `@misc`.** `plainnat.bst` has no `@software`, so the
   entry would be dropped without an error.
3. **Bare `_` is escaped.** An unescaped underscore puts LaTeX into math mode
   and collapses every space for the rest of the field.

## Known gaps in this build

- Three entries still lack fields: empty author in `gptsniffer2024`, empty
  journal and year in `abuhamad2019`. These are the real TODOs in
  `../references.bib`, now visible as BibTeX warnings rather than hidden
  behind parse errors.
- The title page is a working version; check it against the department's
  prescribed format.
- `lmodern` and `microtype` are loaded only if present, so the build works on
  a minimal TeX installation. On MiKTeX both will load.
